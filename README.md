# scoop-bucket

Scoop bucket for [OmniBuild](https://github.com/mukesh-craft/omnibuild).

```powershell
scoop bucket add omnibuild https://github.com/mukesh-craft/scoop-bucket
scoop install omnibuild
omnibuild --version
omnibuild doctor
```

`v0.1.1` provides Windows x64. The Windows ARM64 hash is a placeholder until that release asset is published; do not claim ARM64 support until the hash and install check are verified.
